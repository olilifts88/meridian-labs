What we can learn and what is still missing
Compare the two instruction styles within each AI, then compare AIs using the same instructions. Two examples per workflow give us an initial signal, not a reliable overall winner. Your reviews check this development sample; they are not a separate unseen test.
Time covers generation, sign-in and local dispatch, with local checks recorded separately. Tokens include failed attempts when receipts expose them. Missing measurements stay unavailable. The cost section values all recorded attempts, including failures. Its cost per check-passing answer is not a human-verified success rate or your subscription bill. Building this system and reviewing answers also takes time and model allowance outside the pilot totals.




One reusable method
  1. Freeze the input evidence and version the criteria before comparing outputs.
  2. Run the workflow-specific evaluator and keep every criterion result.
  3. Check normal, missing-evidence, duplicate and deliberately incorrect cases.
  4. Compare candidates on the same cases, sources and rubric.
  5. Keep human verdicts and execution receipts separate from automated checks.
