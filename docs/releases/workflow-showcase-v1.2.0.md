# AI Workflows v1.2.0

Follow each workflow from its evidence and model route to reviewed output pages.

- Transcript to action: four conversation scenarios, account updates, engineering signals, commercial follow-ups, team posts and a searchable call library.
- Vulnerability review: 40 asset findings with versions, owners, SLA deadlines, mitigations and exception requests.
- Security questionnaires: 20 questions, 12 policy sources and an evidence-request register.
- SOC 2: 16 controls, source periods and owner follow-ups.
- Release notes: four examples, supported revisions and approved product-update pages.
- Simpler navigation, clear destination labels, editable route budgets and named one-model cost comparisons.

Download `meridian-ai-workflows.zip`, extract it, and run `python3 showcase_demo.py` (Windows: `py showcase_demo.py`). Python 3.9+ is required; no packages or model credentials are needed. Use `--offline` to retain the saved rate card without a pricing check.

The original forty recorded model answers remain supporting evidence. New prepared business scenarios do not add measured model results. Approvals create browser-owned demo pages, without sending messages or updating external systems. Model routes price planning token assumptions; changing them does not generate another answer.

The package manifest and attached SHA-256 checksum verify its files. See the included README for the full review path and storage behaviour.
