# AI Workflows v1.2.1

Output evaluations now appear automatically beside the artefact after Run workflow.

- Visible source-check results, failed criteria and correction receipts for each example.
- Expandable recorded model answers only where the input evidence matches.
- A short staggered reveal, with immediate display for reduced-motion preferences.
- Saved release and business results reopen with the evaluation and artefact.
- Route settings remain available before running. Source links open the relevant evidence sections.

Download `meridian-ai-workflows.zip`, extract it, and run `python3 showcase_demo.py` (Windows: `py showcase_demo.py`). Python 3.9+ is required. Open the printed localhost address; no packages, AI sign-in or model credentials are needed. Use `--offline` to retain the saved rate card without a web check.

The ZIP uses the same browser assets and prepared data as the hosted version. The original forty recorded answers remain unchanged; prepared or revised outputs do not inherit model-comparison scores. Existing approval and external-write boundaries remain in place.
