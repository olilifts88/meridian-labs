## Visitor path

Home → choose workflow → inspect sources and route → Run workflow → review checks and proposed records → approve → destination hub and output pages. Saved results retain the route, evidence snapshot, reviewer note and approval. Request changes supports a specific correction or a saved note; arbitrary notes are not described as generated revisions.

Release revisions can restore missing customer actions and add explicit source-backed steps. Before/after and source-bound approval remain visible. The original release evidence and recorded answers are retained.

The main navigation contains Workflows and Saved results. Generic benchmark scorecards are replaced by a plain review-method page; original model comparisons remain supporting evidence. Estimates remain token-budget calculations, distinct from measured model performance.
