# Skill: triage a repeated knowledge gap

Status: portfolio example. All examples and IDs are fictional.

## Purpose

Turn repeated unanswered questions into a specific documentation improvement, with the product evidence and audience attached. The goal is for the next person to complete the task without searching across several outdated pages.

## Inputs

- A grouped question with source channel and count, without unnecessary personal data.
- Existing guide and approved product evidence, including pull requests where available.
- Confirmed rollout audience for the workflow.

## Decision

For three or more similar questions, check whether the current guide is missing, stale, fragmented or correct but hard to find. Propose one of: a small correction, a fuller guide, a new guide or a routing change. Include links to the evidence, what the proposed change fixes for the user, and the review route. Do not draft a guide for a workflow that is unconfirmed or unavailable to the intended audience.

Routine corrections can follow configured automated checks and selective review. A genuinely new guide requires an engineer's input and approval. Log the decision and use the same question as a saved evaluation case after the change.
